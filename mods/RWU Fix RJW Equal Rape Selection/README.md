# RWU Fix RJW Equal Rape Selection

Минимальный фикс выбора принудительных событий RJW для пешек с чертами `Rapist`, `Necrophiliac` или `Zoophile`.

При каждой попытке выбрать работу мод перемешивает четыре типа с равной вероятностью:

- Comfort prisoner;
- Random rape;
- Necrophilia;
- Bestiality.

Если выбранный тип сейчас недоступен (нет подходящей цели, выключен настройкой или не подходит черта пешки), он исключается, после чего выполняется равновероятный выбор среди оставшихся типов. Пул целей штатного `RandomRape` не меняется: животные продолжают учитываться RJW наравне с остальными допустимыми целями.

Настроек и Harmony-патчей нет. Мод добавляет одну приоритетную ветку в think tree RJW и требует загрузки после RimJobWorld.

## Сборка

```bash
./Source/RWUEqualRJWSelection/build.sh
```

Скрипт собирает `1.6/Assemblies/RWUEqualRJWSelection.dll` против установленного RimWorld 1.6 и `rjw/1.6/Assemblies/RJW.dll`.
