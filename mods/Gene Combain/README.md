# Gene Combain

Генный комбайн 3×2 для Biotech извлекает случайные гены, выдирает выбранный ген или удаляет ген. В меню здания один список доноров с пометками для трупов и шамблеров. Для самостоятельного входа используется ПКМ по комбайну.

- Ксеногенетика открывает комбайн и случайное извлечение.
- Генный процессор открывает летальное извлечение у живых и одно извлечение выбранного гена из свежего трупа.
- Архогенетика открывает удаление гена у живых.
- Содержание сущностей из Anomaly добавляет живых шамблеров на платформах в списки извлечения.
- Компактный комбайн 1×2 требует включённый Vanilla Gravship Expanded — Chapter 1 и исследованные «Компактные рабочие места».

Обычный комбайн потребляет 1000 Вт, компактный — 500 Вт. Обработка занимает 12 игровых часов. Ход процедуры виден по полосе над капсулой. Во время обработки силуэт пульсирует поверх пациента на лежанке.

Для разработки соберите DLL командой `bash Source/build.sh 1.6` или `bash Source/build.sh 1.7` с игровыми библиотеками соответствующей версии. Для нестандартной установки укажите каталог библиотек в `RIMWORLD_MANAGED`.

Скрипт заменяет DLL целиком после успешной компиляции. После сборки перезапустите RimWorld, чтобы игра загрузила новую DLL.
