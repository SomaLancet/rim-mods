# RWU Translation Simply More Implants

Полный русский перевод [Simply More Implants](https://steamcommunity.com/sharedfiles/filedetails/?id=2616600036) для RimWorld 1.6.

- Переведены названия и описания всех имплантов, состояний и операций установки/снятия.
- Переведены медицинский компонент, рецепт его изготовления, вкладка и проекты исследований.
- Переведены настройки отключения техпринтов.
- Включены строки для контента Royalty, Ideology и опционального Vanilla Psycasts Expanded.
- Оригинальный workshop-мод не изменяется, поэтому обновления Steam не перезаписывают перевод.

## Порядок загрузки

Загружать после Simply More Implants (`turnovus.morebionicimplants`). Метаданные перевода уже задают обязательную зависимость и правильный порядок.
