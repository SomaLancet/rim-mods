# RWU Fix Genepack Reprocessor Settings

Локальный UI-фикс для RimWorld 1.6 и Genepack Reprocessor.

- Показывает настройку расходования исходных генопаков, даже когда она выключена.
- Исправляет высоту блоков разделения, слияния и переработки: она рассчитывается по доступным элементам управления, а не по текущему значению галочки.
- Заменяет неясную русскую подпись «Использовать генные пакеты» на «Расходовать исходные генопаки» и прямо объясняет результат во всплывающей подсказке.
- Не меняет сохранённое значение автоматически: после включения мода нужную галочку следует включить в разделе слияния.

Загружать после Harmony, Genepack Reprocessor и, если он используется, Genepack Reprocessor (Ru translation).
