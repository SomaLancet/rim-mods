# RWU Fix Distress Call Arrival

Локальный compatibility-патч для RimWorld 1.6, не позволяющий генерации карты сигнала бедствия уничтожить прибывающий челнок вместе с пассажирами.

- заменяет `ParentRelationUtility.GetParent` эквивалентной null-safe реализацией: повреждённая связь `Parent` без `otherPawn` игнорируется, а корректные родители находятся как обычно;
- благодаря этому генерация пешек RJW Sexperience / RJW Genes не падает на унаследованных повреждённых связях;
- дополнительно защищает только `DistressCallUtility.SpawnCorpses`: пустой или содержащий `null` список убийц больше не вызывает `NullReferenceException` в `HealthUtility.SimulateKilledByPawn`;
- если убийца отсутствует, жертва создаётся обычным трупом без указанного виновника, после чего ванильный код продолжает выставлять время смерти, гниение, позицию, кровь и запрет;
- каждая обнаруженная повреждённая родительская связь и резервный сценарий без убийц записываются в `Player.log` один раз.

Основной сценарий проверки: загрузить `second age — 5`, снова отправить транспорт на сайт `Сигнал бедствия от фракции Херхерхерни` и убедиться, что карта открывается, а пассажиры высаживаются. В логе не должно быть `Ref 9903CC42` / `Exception in transport pods arrival action`.

Загружать после Harmony. RJW Sexperience, RJW Genes, Vanilla Social Interactions Expanded и Humanoid Alien Races указаны только в `loadAfter`; обязательными зависимостями они не являются.
