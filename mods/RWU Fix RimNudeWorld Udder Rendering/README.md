# RWU Fix RimNudeWorld Udder Rendering

Минимальный визуальный патч для RimJobWorld и RimNudeWorld 4.1.1.7 под RimWorld 1.6.

RimNudeWorld выбирает графику груди по точному `defName` хедиффа и не учитывает `UdderBreasts`, хотя RJW относит вымя к семейству груди. Мод добавляет `UdderBreasts` в существующие условия левой и правой груди и сосков человека. Используются штатные спрайты RimNudeWorld, а их размер определяется настоящим `Severity` вымени.

Патч не изменяет сам `UdderBreasts`, его `genitalFamily`, `CanLactate`, операции, лактацию, рост при беременности или содержимое сохранений. Если у пешки одновременно присутствуют обычная грудь и вымя, RimNudeWorld по-прежнему отдаёт приоритет обычной груди.

Поддерживаются человеческие пешки с `ThingDef` `Human`. HAR-расы, для которых RimNudeWorld создаёт отдельные наборы body addons, этим минимальным патчем не затрагиваются.
