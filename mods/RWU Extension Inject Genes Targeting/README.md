# RWU Extension Inject Genes Targeting

Отдельное расширение для RimWorld 1.6 и мода [Inject Genes](https://steamcommunity.com/sharedfiles/filedetails/?id=2918091446).

- После выбора исполнителя правый клик по поддерживаемому генпаку показывает действие «Применить к...».
- После выбора цели исполнитель резервирует и забирает один генпак, подходит к цели и применяет к ней штатный эффект Inject Genes.
- Допускаются живые humanlike-колонисты, пленники и рабы колонии, включая самого исполнителя.
- Цель с уже имеющимся геном из генпака выбрать нельзя — используется исходная проверка Inject Genes.
- Для обычных колонистов вызывается исходная реализация Inject Genes. Для пленников и рабов расширение повторяет то же добавление отсутствующих генов, настройку эндо-/ксеногенов и генетическую кому, обходя только встроенный запрет по статусу пешки.
- Поддержка автоматически распространяется на все генпаки, которым Inject Genes добавил свой компонент: ванильный `Genepack`, а также совместимые предметы Alpha Genes, Split Genepack и WVC - Xenotypes and Genes при наличии этих модов.
- Встроены английская и русская локализации. Корневая папка `Languages` явно подключена через `LoadFolders.xml`, поэтому перевод работает и с языковой папкой `Russian (Русский)` из актуального RimWorld-ru.
- Оригинальный workshop-мод не изменяется.

## Зависимости и порядок загрузки

- RimWorld - Biotech
- Inject Genes (`Zaf.InjectGene`)

Загружать после Inject Genes. Метаданные мода уже задают эту зависимость и порядок.
